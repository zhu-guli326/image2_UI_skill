# Current itinerary demo

Open `index.html` in a browser. This is a static, responsive mobile itinerary prototype with date selection, expandable stops, a completion state (Shift-click a stop), navigation feedback, and an accessible add-stop sheet.

The visual asset is an existing verified `image2` output copied from this repository and recorded in `assets/lisbon-coast-hero.png.provenance.json`. All labels, UI chrome, controls, and icons are rendered in HTML/CSS/SVG.
