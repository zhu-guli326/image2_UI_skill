# Mimo Activities

`index.html` is a native 9:16 schedule prototype. Its core interaction is a perspective card carousel: users can drag horizontally, use previous/next controls, or click an edge card to bring it into focus. Bottom tabs switch Today, Progress, and Profile.

`assets/mimo-pills.png` is a Youtoken `gpt-image-2` image-edit asset. Cards, text, gesture interaction, icons, status information, and navigation are code-rendered.
