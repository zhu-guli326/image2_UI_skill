# CleanBite Scanner

Interactive food-label scanner concept inspired by the supplied lime-green reference.

- Open `index.html` directly for the dual-phone board.
- Use `?embed=1` for a fixed 410 x 846 analysis-screen embed.
- Use `?view=pricing` on narrow screens to open the plan selector first.
- The style-profile effect board and product visual were generated locally through the configured Youtoken `gpt-image-2` channel. All readable interface text, charts, controls, status bar elements, and icons in the clickable demo are code-rendered.
