# FuFu Bakery

`index.html` is a native 9:16 mobile bakery prototype. The welcome screen enters the bakery home; the bottom navigation opens the menu and member card, and every route can return to the home screen.

The dog baker illustration in `assets/fufu-baker.png` is a Youtoken `gpt-image-2` image-edit asset. Text, status bar, controls, navigation, and labels are code-rendered. `mobile-preview.png` is the library poster and `fufu-bakery-demo.mp4` records the main interaction path.
