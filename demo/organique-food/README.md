# Organique Food

`index.html` is a 9:16 iOS meal planner inspired by an editorial organic-food reference. Choose a meal, select delivery days, build the plan, then return to browse more meals.

The meal photography is a local `youtoken-gpt-image-2` asset stored in `assets/chicken-fattoush-salad.png`. The poster is `mobile-preview.png`; the walkthrough is `organique-food-demo.mp4`.
