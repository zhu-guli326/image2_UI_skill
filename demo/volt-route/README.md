# Volt Route

`index.html` is a 9:16 EV charging prototype. Use the bottom tabs to switch between dashboard, route, and charge status. The control on the charging screen pauses and resumes charging.

The unbranded vehicle photo and unlabeled map texture are local `youtoken-gpt-image-2` assets. The poster is `mobile-preview.png`; the walkthrough is `volt-route-demo.mp4`.
