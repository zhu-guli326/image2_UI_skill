# Lumen Journal

A single-screen, clickable iOS-style travel journal concept.

Open `index.html` directly in a browser, or serve the repository root with a static server and open `/demo/lumen-journal/`.

## Asset provenance

- `assets/hero-kayak.png`: Youtoken `gpt-image-2` image generation fallback. It is a local, generated bitmap asset used only for the feature photo.
- Navigation, controls, labels, status indicators, and all readable text are code-rendered.
