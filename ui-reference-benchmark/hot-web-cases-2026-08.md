## 6. 第四批建议新增的网页案例专题

1. **AI Product Launch**：产品 hero、互动 demo、use cases、pricing、FAQ、signup。
2. **Developer Tool Marketing Site**：代码示例、API、文档、模板和产品入口。
3. **Pricing Decision Lab**：套餐比较、试用、支付、升级/降级、失败与成功状态。
4. **Creator Tool Website**：产品演示、模板库、作品样例和 workspace 登录。
5. **Learning Catalog**：课程目录、筛选、试听、讲师、购买和学习 dashboard。
6. **Luxury Fashion Shop**：collection、PLP、PDP、cart drawer、checkout。
7. **Restaurant Booking**：品牌、菜单、菜品、日期/人数、座位、确认与取消。
8. **Redesign Story**：旧版问题、迭代选择、前后对照、真实结果与复盘。

## 实施判断

这批的热门视觉有两条容易误用的趋势：过度玻璃化和将真实产品 UI 当背景图。两个都可以用于 hero，但页面仍必须保留真实的可读文字、可操作 CTA、状态及移动端重排。对 image2 UI 来说，营销资产属于 image2；定价、表单、菜单、筛选和结账必须保持代码界面。
