## 第五批建议新增的 7 个案例专题

1. **Daily Planner**：收件箱、时间块、专注、提醒、完成/撤销。
2. **AI Task Assistant**：AI 建议、确认、调整日程、冲突和恢复。
3. **News & Podcast Reader**：频道、文章、保存、音频、订阅和离线。
4. **Market Briefing**：金融新闻、自选、行情、提醒和风险标签。
5. **Food Delivery Journey**：发现、菜单、加购、支付、追踪、评价和退款。
6. **Restaurant Operations**：订单、库存、出餐、配送异常和商家分析。
7. **Smart Home Control Center**：家庭、房间、设备、场景、能耗、离线和权限。

## 选择建议

若下一阶段只做三个高价值案例，选 **AI Task Assistant**、**Food Delivery Journey**、**Smart Home Control Center**。三者分别覆盖复杂表单/日历、交易与实时追踪、设备控制与异常状态，能最大化验证 image2 UI 的“资产 + 代码 UI + 交互状态”能力。
