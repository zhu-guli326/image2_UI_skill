## 来源说明

- **Dribbble `Popular`**：提供当前热门视觉和组件趋势，适合视觉、布局和状态命名参考。
- **Behance `appreciations`**：项目页通常有更完整的页面序列，适合提炼流程和系统语言。
- **Awwwards `SOTD`/`SOTM`**：适合旗舰网页、媒体叙事和交互节奏；必须控制性能、动效与无障碍风险。

## 使用顺序

1. 从“按产品类型”选择最接近的专题，先阅读该专题的状态要求。
2. 选一条完整任务流，而不是拼接多张无关 screenshot。
3. 使用 [fields.yaml](fields.yaml) 记录来源、可复用组件、媒体、状态与实现风险。
4. 结合 [recommendations.md](recommendations.md) 的优先级，优先实现数据、控件和反馈，再考虑高成本视觉效果。
