# UI 界面词典

把截图、设计稿或 App 参考图转成可点击 Demo 时，请使用这份词典。先准确说出屏幕上有什么，再决定它应该由代码实现，还是交给 `image2` 生成。

## 核心原则

按照界面的功能角色来描述，不要只说模糊的外观。

- 不推荐：“一排盒子”
- 更准确：“卡片网格上方的一组筛选标签”
- 不推荐：“一个浮起来的东西”
- 更准确：“带半透明遮罩的底部抽屉”
- 不推荐：“一些图片卡片”
- 更准确：“由媒体图块和代码文字说明组成的瀑布流画廊”

## 页面结构

| 模式名称 | 含义 | 通常由代码实现？ | 适合 image2？ |
| --- | --- | --- | --- |
| 应用框架 | 应用持续存在的外层框架：导航、内容区和安全区 | 是 | 否 |
| 顶部应用栏 | 包含标题、返回、菜单、搜索或操作的顶部栏 | 是 | 否 |
| 导航栏 | 网站级链接与主要操作 | 是 | 否 |
| 侧边栏 | 垂直导航或工作区列表 | 是 | 否 |
| 导航轨 | 仅使用图标的紧凑侧边导航 | 是 | 否 |
| 底部标签栏 | 位于移动端底部的主要页面入口 | 是 | 否 |
| 首屏主视觉 | 页面第一个主要视觉区域，通常由文字和媒体组成 | 文字与控件：是 | 媒体：是 |
| 内容区段 | 只承担一项主要任务的通栏页面区段 | 是 | 有时 |
| 页脚 | 次要链接、联系方式、许可与法律信息 | 是 | 否 |

## 控件

| 模式名称 | 用途 | 注意事项 |
| --- | --- | --- |
| 按钮 | 执行一个直接命令 | 包含悬停、按下、禁用和加载状态 |
| 图标按钮 | 用图标承载紧凑操作 | 必须提供无障碍名称 |
| 分段控件 | 互斥的视图模式 | 适合网格 / 列表、浅色 / 深色切换 |
| 标签页 | 在同一语境中切换关联面板 | 标签文字要简短 |
| 筛选标签 | 缩小内容集合范围 | 适合案例库、商店、搜索和画廊 |
| 搜索框 | 查询本地或远程内容 | 提供空状态和无结果状态 |
| 复选框 | 多个互相独立的二元选择 | 标签文字放在方框旁边 |
| 开关 | 单个开关设置 | 适合需要持续保存的设置 |
| 滑杆 | 数值范围控制 | 需要精确操作时显示当前值 |
| 步进器 | 小幅增加或减少数值 | 适合数量与间距控制 |
| 菜单 | 次要操作或选项集合 | 不要把主要操作藏进菜单 |
| 工具提示 | 解释不熟悉的图标 | 不要只在提示中放关键说明 |

## 内容模块

| 模式名称 | 外观结构 | 最适合 |
| --- | --- | --- |
| 卡片网格 | 按行列重复排列的卡片 | 商品、文章、模板、案例 |
| 便当网格 | 具有层级的混合尺寸图块 | 功能导览与能力概览 |
| 瀑布流 | 高度不同、错落排列的卡片 | 视觉画廊与灵感板 |
| 信息流列表 | 按时间或排名排列的行 | 新闻、更新、动态、消息 |
| 媒体图块 | 图片或视频为主，文字为辅 | 作品集与视觉素材库 |
| 商品卡片 | 商品图、名称、价格与操作 | 电商与目录页面 |
| 数据条 | 紧凑的数字摘要 | 真实指标、数量与审计结果 |
| 对比表 | 逐行对比功能 | 套餐或技术差异 |
| 详情面板 | 展示选中项目的详细信息 | 检查器、文件详情、商品详情 |
| 时间线 | 按时间排序的事件 | 发布记录、历史、引导流程 |
| 分步流程 | 带进度的多步骤流程 | 设置、结账、表单 |

## 浮层与临时界面

| 模式名称 | 功能 | 注意事项 |
| --- | --- | --- |
| 模态框 | 打断当前流程并聚焦一项任务 | 需要焦点锁定和关闭行为 |
| 抽屉 | 从侧边滑出导航或详情 | 适合响应式布局 |
| 底部抽屉 | 从底部出现的移动端友好面板 | 通常搭配遮罩 |
| 弹出框 | 出现在触发元素附近的小型上下文界面 | 适合轻量选项 |
| 命令面板 | 键盘优先的操作与搜索浮层 | 通常使用 Command K 打开 |
| 轻提示 | 短暂反馈 | 不用于持续性错误 |
| 横幅提示 | 页面顶部附近的持续消息 | 适合警告、试用或同步状态 |

## 状态词典

| 状态名称 | 出现时机 | 实现提示 |
| --- | --- | --- |
| 加载骨架屏 | 内容到达之前 | 与最终布局形状保持一致 |
| 空状态 | 集合中还没有内容 | 提供一个明确的下一步 |
| 无结果状态 | 搜索或筛选没有匹配项 | 保留当前查询条件 |
| 错误状态 | 请求或操作失败 | 说明恢复方法，并尽可能提供重试 |
| 禁用状态 | 操作当前不可用 | 原因不明显时要说明 |
| 选中状态 | 某个项目处于激活状态 | 使用对比度，不要只依赖颜色 |
| 悬停状态 | 指针位于交互元素上方 | 使用变形或颜色，不要引发布局位移 |
| 按下状态 | 按钮正在被触发 | 轻微的物理反馈通常有效 |
| 焦点状态 | 键盘焦点出现 | 必须清晰可见且具有高对比度 |
| 成功状态 | 操作完成 | 保持简短，并在需要时允许撤销 |

## 资产拆分命名

在 `code-ui` 和 `image2-assets` 清单中使用这些标签。

| 标签 | 归属 | 示例 |
| --- | --- | --- |
| `code-text` / 代码文字 | 代码 | 标题、正文、标签、价格 |
| `code-control` / 代码控件 | 代码 | 按钮、标签页、输入框、滑杆 |
| `code-icon` / 代码图标 | 代码 | 搜索、返回、关闭、菜单、收藏、播放 |
| `code-status` / 代码状态 | 代码 | 电池、Wi-Fi、信号、进度、徽标 |
| `layout-chrome` / 界面框架 | 代码 | 设备边框、安全区、应用框架 |
| `photo-asset` / 照片资产 | image2 | 生活方式照片、首图、编辑封面 |
| `product-cutout` / 商品抠图 | image2 | 透明或干净背景上的物体 |
| `texture-asset` / 纹理资产 | image2 | 纸张、玻璃、织物、墙面、渐变质感材料 |
| `illustration-asset` / 插画资产 | image2 | 角色、地图、复杂场景 |
| `thumbnail-asset` / 缩略图资产 | image2 | 卡片封面、文章图片、画廊图块 |

## 模式配方

### 素材库页面

当参考页面包含大量案例、资产、课程或模板时使用。

- 顶部应用栏
- 侧边栏或分类导航轨
- 搜索框
- 筛选标签或分类按钮
- 数据条
- 卡片网格、瀑布流或媒体图块
- 详情抽屉或预览模态框
- 空状态与无结果状态

### 移动端商品详情

当一个物体或地点是页面焦点时使用。

- 设备边框与安全区
- 带返回操作的顶部应用栏
- 首屏媒体或商品抠图
- 标题区
- 价格或元数据行
- 分段详情标签
- 吸底操作栏
- 相关卡片横向列表

### 编辑式信息流

当页面用于阅读与发现时使用。

- 顶部应用栏
- 主题标签页
- 重点文章卡片
- 信息流列表
- 媒体图块
- 收藏与分享图标按钮
- 加载骨架屏
- 无结果状态

### 轻量仪表盘概览

当页面需要数据指标，但不是高密度后台工具时使用。

- 应用框架
- 顶部工具栏
- 数据条
- 洞察卡片
- 图表面板
- 动态信息流
- 筛选器
- 空、加载与错误状态

## 命名检查清单

开始实现前，先写一份简短清单。

```text
code-ui / 代码界面：
- 应用框架
- 顶部应用栏
- 搜索框
- 筛选标签
- 瀑布流卡片网格
- 详情抽屉
- 空状态

image2-assets / image2 资产：
- 首屏媒体：1600x900 照片资产
- 卡片封面：4 张缩略图资产，4:3 裁切
- 物体抠图：透明背景商品抠图
```

如果清单中出现“带文字的图片”，请再次拆分。除非文字本身属于真实照片、扫描文档或艺术作品，否则文字应由代码渲染。
